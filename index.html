Full-stack · Payments · Security

Chale Pass

An event ticketing platform for Ghana. Organisers sell tickets, buyers pay with mobile money or card, and door staff scan guests in with any phone.

  • Tickets that can't be faked: QR codes change every 30 seconds (HMAC-signed), so screenshots stop working within a minute.
  • Fast gates, even offline: each scan is decided on the phone in under 5 ms and synced to the server in about 250 ms.
  • Money handled safely: Paystack split payments, refunds and cancellations, organiser ID checks and held payouts for new organisers.
  • Crowd control: live headcount, venue capacity, a control room for organisers, and fake-ticket alerts.

Security · Open source

SiteCheck

A free website security checker. Type in a website and get an A-F report in plain English: what's wrong, why it matters and how to fix it - built for small businesses, schools and churches.

  • Checks what attackers see first: HTTPS, security headers, cookies, exposed secrets and backups, outdated software, email spoofing protection.
  • Can't be turned into a weapon: blocks server-side request forgery by checking every IP address at connection time - including inside its screenshot browser.
  • Honest results: recognises bot-protection and error pages instead of grading them, and never raises false alarms on "page not found" pages.
  • Tested: 24 automated tests, including a deliberately insecure fake website.

AI agent · Voice · Safety

Jarvis

A voice-controlled AI assistant for my laptop and Android phone. Say "Hey Jarvis" and it can open apps and files, play music, read and reply to messages, and run my day.

  • An agent with tools: the model chooses from Python tools I wrote; my code decides what actually runs.
  • Private by design: wake word and speech recognition run on the laptop, so no audio leaves it until you say "Hey Jarvis".
  • Safety enforced in code, not trusted to the AI: risky actions need approval and default to no; a locked phone can only use harmless tools.
  • Phone link: a private Tailscale network, with one-time tokens on every approval button.
